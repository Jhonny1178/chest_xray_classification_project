# Project: Chest X-ray classification (Pneumonia vs Normal)

**Author:** Jan Nowojski

## 1. Description
The project uses a ResNet18 neural network (Transfer Learning) to classify chest X-ray images into two categories: **NORMAL** (healthy) and **PNEUMONIA** (sick).
